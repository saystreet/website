# SayStreet brand kit

Files the site serves are in `public/brand`: `lockup-for-dark-bg.svg` (header and footer logo), `app-icon.svg` and `app-icon-1024.png` (favicon and touch icon). Everything else is here.

| File | Use |
|---|---|
| `lockup-on-navy.png`, `.svg` | Mark and name on navy, ready to send or place in a slide |
| `lockup-for-dark-bg.png` | The same on a transparent background, for dark backgrounds |
| `lockup-for-light-bg.png`, `.svg` | In navy, for light backgrounds |
| `mark-yellow.svg`, `mark-yellow-1000.png` | The mark alone, for dark backgrounds |
| `mark-navy.svg` | The mark alone in navy, for light backgrounds |
| `wordmark-light.svg`, `wordmark-navy.svg` | The name alone |

Lettering in the SVG files is outlined, so they look the same without the font.

## The mark
Dots 2, 3 and 4 of a Braille cell spell the letter S. The lit dots use the full colour, the other three the same colour at 30%.

## Colours
- Navy `#0a1124`
- Yellow `#ffd166`
- Off-white `#eef0f6`

## Type
- Display and wordmark: Big Shoulders Display, weight 900, uppercase
- Text: Albert Sans
- Prices and codes: Red Hat Mono

All three are free under the SIL Open Font License.
